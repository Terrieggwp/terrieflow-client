# Как работает TerrieFlow Client

## Аккаунт и подписка

Вход через Telegram открывает системный браузер и возвращает короткоживущую сессию в приложение. Вход по почте отправляет учётные данные непосредственно API TerrieFlow. Сессионный секрет сохраняется в Windows Credential Manager, пароль — нет.

После входа клиент получает профиль и доступную VPN-подписку, импортирует её в локальный профиль TerrieFlow и синхронизирует при запуске и ручном обновлении. Grace-период считается активным доступом. Если доступ действительно истёк, подключение блокируется, маршруты скрываются и показывается экран продления. Ручная внешняя ссылка остаётся отдельным локальным профилем.

## Два сетевых ядра

Mihomo управляет TUN, DNS, правилами, группами, измерением задержки и выбором маршрута. Xray обслуживает транспорты, которых нет в Mihomo. При необходимости Mihomo передаёт такой трафик Xray через локальный SOCKS-мост.

```text
приложения → TUN / системный прокси → Mihomo → сервер
                                      └→ локальный SOCKS → Xray → сервер
```

Режим без TUN использует системный прокси Windows и не требует прав администратора, но охватывает только приложения, которые учитывают системные настройки прокси.

## Процессы и привилегии

- `TerrieFlow.exe` показывает UI и работает от текущего пользователя.
- `multicore-daemon.exe` хранит сетевое состояние и принимает команды только через аутентифицированный loopback-канал.
- `multicore-core-host.exe` запускается с повышением прав только для TUN/ядер и общается с daemon через защищённый локальный канал.
- Xray и Mihomo запускаются из проверенного комплекта и завершаются вместе с хостом.

Внутренние имена `multicore-*`, имя TUN и `%LOCALAPPDATA%\MultiCore` пока сохранены для совместимости. Пользовательский продукт и установщик называются TerrieFlow.

## Обновление

Официальная сборка проверяет только `Terrieggwp/terrieflow-client`. Клиент принимает числовую версию, выбирает точный Windows x64 asset, проверяет архитектуру, размер, SHA-256, безопасно распаковывает обновление и поддерживает откат. `release.txt` служит дешёвым указателем и меняется только после успешной публикации полного GitHub Release.

Первый beta-релиз поддерживает Windows 10/11 x64. Другие платформенные реализации остаются в исходном коде, но не входят в официальный комплект.
