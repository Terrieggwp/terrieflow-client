# TerrieFlow Client Roadmap

## Версия 0.1

Цель:
Создать UI-прототип клиента.

Функции:

- экран приветствия;
- авторизация;
- отображение подписки;
- список серверов;
- выбор режима подключения;
- кнопка подключения (mock).

## Версия 0.2

Добавить:

- API интеграцию;
- получение подписки;
- синхронизацию состояния.

## Версия 1.0

Добавить:

- реальное VPN ядро;
- Android;
- iOS;
- desktop.
