TerrieFlow Logo Kit v1.0

This package is an accurate vector reconstruction based on the supplied raster
references. It fixes one master geometry for the TF monogram across every file.

Core logo:
- White T + blue-to-cyan F for dark backgrounds.
- Ink T + blue-to-cyan F for light backgrounds.
- The shield and neon circle are optional marketing devices, not part of the mark.

Clear space:
- Minimum 1X on every side.
- X equals the visual width of the white T stroke.

Minimum sizes:
- Compact symbol: 24 px on screen / 6 mm in print.
- Horizontal logo: 120 px on screen / 28 mm in print.
- Glow version: symbol from 64 px; horizontal from 220 px.

Colors:
- Terrie Cyan: #16E0F5 / RGB 22, 224, 245
- Terrie Blue: #2F6BFF / RGB 47, 107, 255
- Midnight: #070B16 / RGB 7, 11, 22
- White: #F7FAFF / RGB 247, 250, 255
- Ink: #0A1020 / RGB 10, 16, 32

For production, prefer SVG. Use glow only in marketing compositions.
